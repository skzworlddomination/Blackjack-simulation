## Project Overview:

Simple Blackjack simulation in C for beginners to learn the game without financial risk.

## Installation Instructions:

### Prerequesites:
-GCC compiler

-make

On Ubuntu/Debian:

```bash
sudo apt install build-essential
```

On macOS:

```bash
xcode-select --install
```
## Usage

### Build
To run the program:

```bash
make
```

then run:
```bash
./blackjack
```
